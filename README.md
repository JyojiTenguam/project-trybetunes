
# 🎵 TrybeTunes

Aplicação web que permite aos usuários pesquisar músicas, ouvir previews, favoritar faixas e editar seu perfil. Desenvolvida com React, TypeScript e Vite como parte do módulo de Front-end da Trybe.

## ✨ Demonstração

> A aplicação oferece uma interface intuitiva para explorar músicas, gerenciar favoritas e personalizar o perfil do usuário, utilizando dados de uma API externa.

## 💡 Sobre

O TrybeTunes é uma aplicação que permite:

- Pesquisar por músicas e artistas
- Ouvir previews das faixas
- Adicionar músicas aos favoritos
- Editar informações do perfil do usuário

O projeto foi desenvolvido com foco em práticas modernas de desenvolvimento front-end, utilizando React com TypeScript e Vite para uma experiência de desenvolvimento eficiente.

## 🛠️ Habilidades desenvolvidas

- Criação de componentes reutilizáveis com React e TypeScript
- Gerenciamento de estado e ciclo de vida de componentes
- Consumo de APIs RESTful
- Gerenciamento de rotas com React Router
- Estilização com Tailwind CSS
- Testes com Vitest e React Testing Library

## 🧪 Tecnologias utilizadas

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Vitest
- React Testing Library
- Axios

## 🚀 Como rodar o projeto

1. Clone o repositório

```bash
git clone https://github.com/tryber/project-trybetunes.git
```

2. Acesse a pasta do projeto

```bash
cd project-trybetunes
```

3. Instale as dependências

```bash
npm install
```

4. Inicie o servidor de desenvolvimento

```bash
npm run dev
```

> A aplicação estará disponível em http://localhost:5173
